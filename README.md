# Instant Focus

Create a smart AI productivity assistant with no authentication or login system.

The application should open directly to the main dashboard without requiring users to create an account, sign in, enter an email, or verify their identity.

Features

Smart Email Generator

Generate professional, clear, context-aware emails from short instructions.

Suggest an appropriate subject line.

Support professional, friendly, concise, persuasive, apologetic, and formal tones.

Improve grammar and clarity while preserving the user's intent.

Provide shorter versions when appropriate.

Meeting Notes Summarizer

Accept meeting notes, transcripts, or pasted text.

Extract key discussion points, decisions, action items, deadlines, and unresolved questions.

Identify responsible people when explicitly mentioned.

Present results in a concise, easy-to-scan format.

AI Planner

Convert goals, tasks, deadlines, and priorities into an actionable plan.

Break large goals into smaller tasks.

Prioritize tasks by urgency and importance.

Suggest realistic schedules.

Clearly show upcoming, overdue, and high-priority tasks.

AI Behavior

Be concise, accurate, and practical.

Ask questions only when essential information is missing.

Never invent facts, deadlines, decisions, or commitments.

Preserve the user's original intent.

Use clear headings and actionable bullet points.

Allow meeting action items to be converted directly into planner tasks.

Allow meeting decisions to generate follow-up emails.

Authentication Requirement

Do not implement authentication, registration, login, logout, password reset, user accounts, OAuth, social login, or email verification.

The application should work immediately as a guest/anonymous user. Keep user data locally in the browser where possible, with no account required.
